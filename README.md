# Fastframe font review evidence

Synthetic Spotifast demo captures for the Fastframe variable fallback font
weight correction. Baseline: Spotifast 0.14.1 and Fastframe v0.14.0.
Candidate: the same app with regular weight coordinates for variable fallbacks.

Linux X11, dark/light, 900x760 and 1400x900. The interactive candidate was
also tested on native Wayland. No personal account data or credentials are
included. This repository is separate from the Fastframe source contribution.
